The founder's generated reference set for HANDOFF 09 Track G, the supply
roles. Every governing image is prefixed `GOVERNING-`.

These are the target for the switch profile sheet, the add a workspace
chooser, the three onboarding forms, the workspace desks, the three listing
labels, the full cost block, and the light mode targets.

Index them into `docs/design/CATALOGUE.md` before building against them, and
read `docs/DESIGN_DIRECTION.md` for how to match a render without importing
its off brand details.

A founder target beats a generated render, always.
