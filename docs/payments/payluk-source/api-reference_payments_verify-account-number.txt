# Verify account number

> Resolves the account name on a bank account, so you can show the customer who they are about to pay before you create the withdrawal.

Take `bankCode` from [Get bank list](/api-reference/payments/get-bank-list). A code from anywhere else, or one cached from an earlier session, may not resolve: the codes belong to whichever provider Payluk currently settles payouts through.
