# Verify payment token

> Resolves an escrow by its payment token. Used by a buyer to inspect a payment link before paying.



## OpenAPI

````yaml openapi.json GET /v1/escrow/verify/{paymentToken}

  description: >-
    Merchant / Business API for the Payluk escrow and payments platform.


    All routes are mounted under `/v1` and authenticated with a secret key.
    Every response uses the standard envelope `{ status, message, data }`.


    **Rate limit.** Each secret key may make **10 requests per minute** across
    all `/v1` routes. Beyond that the API answers `429` with `{ "status": 429,
    "message": "Too many request" }`. Every response carries `RateLimit` and
    `RateLimit-Policy` headers (IETF draft-7) so a client can back off before
    being cut off.


    **IP allowlist.** On production, if you have added IP addresses to the
    allowlist in your dashboard, requests from any other address are refused
    with `403 Unauthorized IP address`. An empty allowlist admits every address.
    Staging never checks the caller's IP.


    **Merchant super-admin scope.** Escrow, milestone-escrow and category routes
    accept any approved business key. Every other route (customers, wallet,
    merchant account, confirming and disputing, additional fee, vault, payments,
    cards, countries, crypto whitelist) requires the key to belong to a merchant
    super-admin account and answers `401 Access denied` otherwise.
````
