## Resuming after a pause

1. Run `git status`. Uncommitted agent work lives in the working tree, or in the WIP snapshot commit if one was pushed.
2. Resume each unfinished agent by its task id with SendMessage, or start a fresh agent with the row above as its brief.
3. Run `npx tsc --noEmit -p apps/web` once, then `npx vitest run --pool=forks --maxWorkers=2` in `apps/web`.
4. Commit, push, confirm CI is green, merge.
